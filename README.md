# Andrew Ng Machine Learning

A collection of Jupyter notebooks containing my implementations and explorations of concepts covered in Andrew Ng's **Machine Learning Specialization** by DeepLearning.AI and Stanford Online, hosted on Coursera. Each notebook combines explanatory notes with hands-on Python implementations of core machine learning concepts.

## Contents

| Notebook                                                           | Description                                                                                                                                       |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`LinearRegression.ipynb`](LinearRegression.ipynb)                 | Implementation of univariate linear regression, including the cost function and gradient descent, applied to a single-feature dataset.            |
| [`MultipleLinearRegression.ipynb`](MultipleLinearRegression.ipynb) | Extension of linear regression to multiple features, covering vectorized cost and gradient computation and feature scaling.                       |
| [`LogisticRegression.ipynb`](LogisticRegression.ipynb)             | Implementation of logistic regression for classification, including the sigmoid function, decision boundary, cost function, and gradient descent. |

More notebooks will be added as I progress through the specialization, including topics such as regularization and neural networks.

## Getting Started

### Prerequisites

* Python 3.8+
* Jupyter Notebook or JupyterLab
* NumPy
* Matplotlib
* Pandas
* Scikit-learn

### Installation

```bash
git clone https://github.com/ktlai1120/Andew-Ng-Machine-Learning.git
cd Andew-Ng-Machine-Learning
pip install numpy matplotlib pandas scikit-learn jupyter
```

### Running the notebooks

Start Jupyter:

```bash
jupyter notebook
```

Then open any `.ipynb` file from the Jupyter interface and run the cells in order.

## Purpose

This repository serves as a personal study log and reference for the concepts, mathematics, and code covered in the course. It is intended primarily for learning and revision rather than as a production-ready machine learning library.
